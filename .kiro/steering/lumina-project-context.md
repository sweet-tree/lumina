# Lumina Project Context

## Project Vision

Lumina is a consciousness practice app with an AI Plant Teacher guide. We're implementing LangGraph-based conversation flows for advanced AI interactions, pattern recognition, and multi-turn dialogue management.

## Current Architecture

- **Frontend**: Next.js 15 with TypeScript, Tailwind CSS, Prisma
- **Backend**: Python FastAPI with RAG system (Qwen models on Nebius)
- **Database**: Prisma with user authentication (NextAuth)
- **AI Core**: LangGraph for conversation flows and state management
- **Styling**: Tailwind CSS with Radix UI components

## Recent Achievements

- ✅ Breathing card implemented with database integration
- ✅ Feature-based architecture established
- ✅ Server Actions pattern adopted
- ✅ Pure CSS animations for performance
- ✅ TanStack Query integration
- ✅ Clean API structure (Server Actions over routes)

## Current Focus: LangGraph Integration

- Advanced conversation flows with state management
- Plant Teacher personality implementation
- Pattern recognition and synthesis
- Multi-turn dialogue capabilities
- Context-aware responses

## Key Design Principles

- **Present moment focus** (Dzogchen: "short moments, many times")
- **Plant Teacher voice** (mystical, neither human nor machine)
- **Ceremonial container** (sacred practice, not productivity tool)
- **Visual beauty** (cards, animations, organic growth metaphors)
- **State-aware interactions** (LangGraph conversation flows)

## Development Approach

- **Incremental transformation** (build on existing foundation)
- **Spec-driven development** (requirements → design → tasks)
- **One feature at a time** (LangGraph core, then advanced features)
- **User learning focus** (explain code concepts as we build)

## Code Standards

- Use TypeScript for all new code
- Prefer custom hooks for complex logic
- Use Tailwind for styling (avoid CSS modules)
- Follow Next.js 15 app directory patterns
- Implement accessibility from the start
- Use LangGraph for AI conversation flows
- Server Actions over API routes
