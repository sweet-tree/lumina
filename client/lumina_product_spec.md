## Product Vision

**Lumina is a mobile-first presence practice tool that helps busy people check in with body, energy, and mind throughout their day using a card-based interface with Socratic AI guidance.**

## Core Philosophy

### Dzogchen Foundation

The product is built on Dzogchen contemplative principles:

1. **"Short moments, many times"** - Brief awareness check-ins throughout the day, not long meditation sessions
2. **Present-moment focus** - Each check-in is fresh, not comparative or narrative-building
3. **Non-grasping** - Socratic questions guide without giving answers to cling to
4. **Post-meditation reflection** - Synthesis happens after the "session" (day), not during

### Three Doors Framework

All practice revolves around three aspects of experience:

- **🫀 Body** - Somatic awareness, physical sensations, tension, needs
- **⚡ Energy** - Emotional states, activation level, depletion/restoration
- **🧠 Mind** - Thoughts, patterns, clarity, what's unspoken

### Key Principles

- **Presence over analysis** - Practice is about awareness, not understanding
- **Frequency over depth** - Many brief check-ins beat one long session
- **Mobile-first** - Designed for moments between meetings, in elevators, during commutes
- **Guided discovery** - AI asks questions (Socratic) rather than providing interpretations

## Core Product Experience

### The Card System

**Cards** are the fundamental unit of practice. Unlike traditional prompts, each card represents a **state of consciousness** - where you actually are right now.

Each card contains:

1. **Front:** 2-3 questions that guide awareness of your current state
2. **Back:** Brief AI reflection based on user's answers
3. **Type:** Body, Energy, Mind, or Integration
4. **State:** Each card maps to a specific condition (e.g., "Body Tension", "Energy Flow", "Mind Clarity")
5. **Deck:** Core Practice (default), with future decks unlockable

### Inspired by Leela (Ancient Consciousness Game)

The card system is inspired by Leela, the ancient Indian "game of self-knowledge" where players move through states of consciousness on a board. In our digital version:

- **Cards = States** - Each card represents where you are (Body Tension, Energy Depletion, Mind Clarity, etc.)
- **Patterns = Snakes/Ladders** - States naturally connect (tension → depletion is descending; awareness → restoration is ascending)
- **Journey = The Board** - Your cards throughout the day trace a path through consciousness
- **Synthesis = The Mirror** - AI helps you see patterns you can't see from inside

**Key Principle:** This isn't gamification. It's consciousness mapping. The "game" is witnessing your journey, not winning.

```
1. Open app
2. Tap "Draw Card"
3. Card reveals your current state (e.g., "Body Tension")
4. Answer 2-3 questions about this state
```

#### Evening:

```
2. Swipe through carousel of today's cards
```

### AI Response System

**Two types of AI responses:**

1. **Mini-Reflections (after each card):**
   - Fast model (GPT-4o-mini or similar)
   - 3-5 second response time
   - 2-4 sentences
   - Socratic when appropriate, reflective when user goes deep
   - Cost: ~$0.002 per card

2. **Daily Synthesis (evening):**
   - Full model (GPT-4 or Claude Sonnet)
   - 30 second response time
   - 2-3 paragraphs
   - Synthesizes all cards from the day
   - Recognizes patterns across body/energy/mind
   - Cost: ~$0.02 per synthesis

**Total cost per active user:** ~$0.03/day = ~$10/year

```python
def get_ai_response_type(user_answer):
```

## Risk Analysis

### Technical Risks

**AI Response Time:**
- **Risk:** 30-second responses break mobile flow
- **Mitigation:** Use fast models for mini-reflections, show engaging loading state

**Cost Scaling:**
- **Risk:** AI costs spiral with user growth
- **Mitigation:** Optimize prompts, use tiered models, monitor usage

**Voice Transcription:**
- **Risk:** Accuracy issues, language support
- **Mitigation:** Start with text, add voice in Phase 2 when proven

### Product Risks

**User Doesn't "Get It":**
- **Risk:** Card metaphor confusing, users expect journal
- **Mitigation:** Strong onboarding, clear value prop, tutorial

**Frequency Doesn't Stick:**
- **Risk:** Users check in once/day instead of multiple times
- **Mitigation:** Gentle reminders, show value of frequency, make it super easy

**AI Feels Generic:**
- **Risk:** Responses feel like ChatGPT, not personalized guide
- **Mitigation:** Excellent prompt engineering, RAG for context, fine-tuning

### Business Risks

**Narrow Market:**
- **Risk:** Only appeals to meditation enthusiasts
- **Mitigation:** Position as stress tool, not spiritual practice

**Hard to Explain:**
- **Risk:** "Card-based presence practice" doesn't make sense
- **Mitigation:** Show don't tell (video, free trial, viral cards)

**Competitive Response:**
- **Risk:** Calm/Headspace copies feature
- **Mitigation:** Move fast, build community, own the niche

## Open Questions / Decisions Needed

1. **Card Selection Algorithm:**
   - Pure random vs smart (time-aware, pattern-aware)?
   - **Recommendation:** Start pure random (MVP), add pattern-aware in Phase 4 (when we have data)

   - Only "Draw Card" or also "Browse Deck" option?
   - **Recommendation:** Draw only for MVP (honors randomness/surrender), add browse in Phase 3

3. **Redraw Allowed:**
   - Can user redraw if card doesn't resonate?
   - **Recommendation:** Yes, allow one redraw per session (like Tarot)

4. **Voice vs Text for MVP:**
   - Which to build first?
   - **Recommendation:** Text (simpler, more reliable), voice in Phase 3

5. **Daily Synthesis Trigger:**
   - Automatic at 9pm or manual button only?
   - **Recommendation:** Manual button (user control), with optional evening reminder

6. **Question Count Per Card:**
   - 2, 3, or 4 questions?
   - **Recommendation:** 2-3, varies by card complexity

7. **Pattern Recognition:**
   - When to start showing journey visualizations?
   - **Recommendation:** After user completes 10+ cards total (enough data for patterns)

8. **State Judgment Risk:**
   - How to prevent users feeling bad about "low states"?
   - **Recommendation:** Language framing in AI prompts, onboarding emphasis on "all states are teachers"

9. **Consciousness Map Complexity:**
   - How detailed should the map be?
   - **Recommendation:** Start with 15-20 core states (MVP), expand to 50+ with premium decks
