## User Journey & State Tracking Philosophy

### Present Moment Only (No Retrospective)

**We do NOT ask about past states:**
- ❌ No "How were you feeling yesterday?"
- ❌ No "Describe your week before using the app"
- ❌ No memory-based state collection
- ❌ No historical narrative building

**We ONLY track current state:**
- ✅ "Where are you RIGHT NOW?"
- ✅ Real-time check-ins
- ✅ Patterns emerge from actual data
- ✅ Truth over story

**Philosophy:**
- Memory is unreliable (narrative bias)
- Present-moment awareness is the practice
- Patterns emerge naturally from consistency
- Like meditation: Always return to NOW

### Two Modes of Engagement

**MODE 1: Daily Check-Ins (Present Moment)**
- Frequency: 3-10x per day
- Duration: 30 seconds each
- Question: "Where are you RIGHT NOW?"
- Purpose: Build awareness muscle, capture data
- Mental mode: Presence, witnessing
- No reflection required

**MODE 2: Weekly Synthesis (Pattern Reflection)**
- Frequency: Once per week
- Duration: 5-10 minutes
- Question: "What patterns emerged this week?"
- Purpose: Integration, learning, insight
- Mental mode: Reflection, understanding
- Deep engagement

**Why Separate:**
- Different cognitive modes (presence vs analysis)
- Different time commitments (quick vs deep)
- Different purposes (data capture vs integration)
- Prevents check-in fatigue
- Maintains habit (check-ins stay fast)

### Data Truth vs Memory Story

**We believe:**
- Real-time data > retrospective memory
- Patterns observed > patterns assumed
- Actual states > narrative about states
- Present moment > reconstructed past

**Example:**
```
❌ BAD: "Think back - were you tense last week?"

✅ GOOD: User checked in 8x last week
         → Data shows: Tension appeared 6x
         → Truth, not story
```

**This is our differentiation:**
- Other apps: Journaling (memory-based)
- Therapy: Talking about past (narrative)
- Us: Real-time consciousness tracking (data)

## Technical Architecture

### Database Schema

```prisma
// User & Auth (existing NextAuth models)
model User {
  id                String    @id @default(cuid())
  email             String?   @unique
  name              String?
  image             String?
  createdAt         DateTime  @default(now())
  
  // Relations
  accounts          Account[]
  sessions          Session[]
  checkIns          CheckIn[]
  progressionState  UserProgression?
  patterns          UserPattern[]
}

// Core States System
model State {
  id                String   @id @default(cuid())
  level             Int      // 1 = core (13), 2 = nuanced (40), 3 = full (72)
  name              String   // "Body Tension"
  slug              String   @unique // "body-tension"
  realm             String   // "body" | "energy" | "mind" | "meta"
  category          String?  // "physical" | "emotional" | "existential" (for nuanced)
  
  // Display
  icon              String   // "🫀"
  color             String   // "#EF4444"
  description       String   @db.Text
  order             Int
  
  // Leela Mapping (hidden from user)
  leelaSquare       Int?     // 1-72 if mapped to Leela
  leelaName         String?  // Traditional Leela name
  plane             String?  // "physical" | "astral" | "causal" | "higher"
  
  // Wisdom Integration
  buddhistConcept   String?  // e.g., "sloth-torpor" (5 hindrances)
  vedicGuna         String?  // "tamas" | "rajas" | "sattva"
  jungianArchetype  String?  // "shadow" | "anima" | etc
  
  // Relationships
  descendsTo        String[] // State slugs (snakes)
  ascendsTo         String[] // State slugs (ladders)
  breaksLoopOf      String[] // State slugs
  parentState       String?  // For nuanced states (e.g., "tension" parent of "physical-tension")
  
  // Relations
  checkIns          CheckIn[]
  aiPrompts         StateAIPrompt[]
  
  @@index([level])
  @@index([realm])
  @@index([slug])
}

// User Check-Ins
model CheckIn {
  id                String   @id @default(cuid())
  userId            String
  stateId           String
  timestamp         DateTime @default(now())
  
  // User Input
  notes             String?  @db.Text // Optional user notes
  
  // AI Response
  aiReflection      String?  @db.Text
  reflectionType    String?  // "socratic" | "reflective" | "pattern" | "doorway"
  
  // Context
  previousStateId   String?  // For transition tracking
  wasLoopBreak      Boolean  @default(false)
  
  // Relations
  user              User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  state             State    @relation(fields: [stateId], references: [id])
  
  @@index([userId, timestamp])
  @@index([stateId])
  @@index([userId, stateId])
}

// User Progression Tracking
model UserProgression {
  id                String   @id @default(cuid())
  userId            String   @unique
  
  // Unlocks
  currentLevel      Int      @default(1) // 1, 2, or 3
  unlockedStates    String[] // Array of state slugs
  checkInCount      Int      @default(0)
  
  // Baseline
  defaultState      String?  // Their "home base" state
  identifiedAt      DateTime?
  
  // Patterns
  primaryLoop       String?  // e.g., "tension-drained-foggy"
  primaryDoorway    String?  // e.g., "awareness"
  
  // Gamification
  streakDays        Int      @default(0)
  lastCheckIn       DateTime?
  longestStreak     Int      @default(0)
  
  // Premium
  isPremium         Boolean  @default(false)
  premiumSince      DateTime?
  
  // Relations
  user              User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  @@index([userId])
}

// Pattern Recognition
model UserPattern {
  id                String   @id @default(cuid())
  userId            String
  
  // Pattern Definition
  type              String   // "loop" | "transition" | "doorway" | "trigger"
  name              String   // e.g., "Monday Morning Tension Loop"
  stateSequence     String[] // Array of state slugs in order
  
  // Statistics
  occurrences       Int      @default(1)
  firstSeen         DateTime @default(now())
  lastSeen          DateTime @default(now())
  avgDuration       Int?     // Minutes
  
  // Context
  timeOfDay         String?  // "morning" | "afternoon" | "evening" | "night"
  dayOfWeek         Int?     // 0-6
  
  // Insights
  breakthroughs     String[] // State slugs that broke this pattern
  effectiveness     Float?   // 0-1 score of doorway effectiveness
  
  // Relations
  user              User     @relation(fields: [userId], references: [id], onDelete: Cascade)
  
  @@index([userId, type])
  @@index([userId, lastSeen])
}

// Weekly Synthesis
model WeeklySynthesis {
  id                String   @id @default(cuid())
  userId            String
  weekStart         DateTime @db.Date
  weekEnd           DateTime @db.Date
  
  // Data
  checkInIds        String[] // Array of CheckIn IDs
  dominantStates    String[] // Most frequent states
  primaryPattern    String?  // Main loop observed
  breakthroughMoment String? // Key turning point
  
  // AI Generated
  synthesis         String   @db.Text
  insights          String[] // Key insights as array
  suggestions       String[] // Practice suggestions
  
  createdAt         DateTime @default(now())
  
  @@unique([userId, weekStart])
  @@index([userId, weekStart])
}

// AI Prompt Templates (for each state)
model StateAIPrompt {
  id                String   @id @default(cuid())
  stateId           String
  
  // Prompt Engineering
  promptType        String   // "initial" | "repeat" | "loop" | "breakthrough"
  template          String   @db.Text
  
  // Wisdom Sources
  leelaWisdom       String?  @db.Text
  buddhistWisdom    String?  @db.Text
  vedicWisdom       String?  @db.Text
  psychologyWisdom  String?  @db.Text
  
  // Relations
  state             State    @relation(fields: [stateId], references: [id])
  
  @@index([stateId, promptType])
}

// Oracle Mode (Premium Feature)
model OracleDraw {
  id                String   @id @default(cuid())
  userId            String
  timestamp         DateTime @default(now())
  
  // Dice Roll
  diceValue         Int      // 1-6
  previousState     String?  // Previous oracle state
  landedState       String   // State slug after roll + snakes/ladders
  finalState        String   // Where they ended up
  wasSnake          Boolean  @default(false)
  wasLadder         Boolean  @default(false)
  
  // AI Interpretation
  interpretation    String   @db.Text
  guidance          String?  @db.Text
  
  // User Response
  userReflection    String?  @db.Text
  
  @@index([userId, timestamp])
}
```
